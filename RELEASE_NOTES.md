## Maui v1.0 — first release

**Maui** is a real system layer for Android: a floating control panel, a live performance
HUD, a game toolbar, a storage cleaner that finds hidden and duplicate files, and an honest
RAM & game booster.

### Highlights
- **Maui Layers** — draggable bubble, expandable control panel, live HUD, automatic game toolbar.
- **Cleaner** — app caches, thumbnails, temp files, logs, empty folders, hidden leftovers,
  files over 100 MB, byte-identical duplicates (MD5-confirmed) and old `.apk` installers.
- **Booster** — real background-process kills plus `pm trim-caches` when root is present.
- **Game Mode** — animation scale 0, background apps stopped, Do Not Disturb, live FPS.
- **Files & Apps** — built-in browser and per-app app/cache/data breakdown.
- **Bilingual** — full English and Arabic (RTL) UI, Material 3 theming.

### Install
1. Download `Maui-v1.0-release.apk` from the assets below.
2. Allow "install from unknown sources" and install.
3. Open **Maui**, then grant the permissions from **Settings → Permissions**.

SHA-256 of the asset is published in the release body.
